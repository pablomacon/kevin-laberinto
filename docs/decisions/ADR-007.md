# ADR-007 — Tiempo autoritativo

## Contexto

Relojes y frecuencias de los clientes no son confiables ni uniformes.

## Decisión

El servidor controla reloj y frecuencia efectiva de movimiento.

## Consecuencias

Las interfaces representan tiempo informado, no resultados oficiales.

## Alternativas consideradas

Temporizadores del navegador, descartados por manipulación y deriva.
