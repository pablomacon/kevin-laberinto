# ADR-004 — Protocolo versionado

## Contexto

Clientes y servidor evolucionarán a ritmos distintos.

## Decisión

Todo mensaje WebSocket incluye versión y usa contratos compartidos.

## Consecuencias

Las incompatibilidades se detectan explícitamente; hay que mantener versiones.

## Alternativas consideradas

Mensajes implícitos sin versión, descartados por fragilidad.
