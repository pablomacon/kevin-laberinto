# ADR-001 — Arquitectura portable

## Contexto

La primera entrega se ejecutará en Node.js local y se prevé Cloudflare.

## Decisión

Un único motor y contratos reutilizables, con adaptadores por plataforma.

## Consecuencias

Los límites se diseñan mediante interfaces; hay trabajo adicional de adaptación.

## Alternativas consideradas

Implementar lógicas separadas por plataforma, descartado por divergencia.
