# ADR-003 — Motor independiente

## Contexto

El dominio debe poder probarse y reutilizarse.

## Decisión

El motor no depende de interfaz, red, Node.js, Cloudflare ni proveedor alguno.

## Consecuencias

Reloj, transporte y persistencia se inyectarán mediante adaptadores.

## Alternativas consideradas

Acoplar el dominio al servidor local, descartado por falta de portabilidad.
